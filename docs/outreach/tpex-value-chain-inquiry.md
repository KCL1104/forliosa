**收件人**：〔證券櫃檯買賣中心 產業價值鏈資訊平台 承辦窗口信箱〕
**主旨**：詢問「產業價值鏈資訊平台」資料於個人投資記帳 App 中引用之授權方式與費用

證券櫃檯買賣中心 產業價值鏈資訊平台 承辦人員 您好：

我們是 Forliosa 的開發團隊。Forliosa 是以台股為主的個人投資記帳與資訊 App，目前**免費**提供給開發者本人與少數家人、朋友使用；
未來可能開放一般使用者註冊，並可能收取訂閱費（屆時屬商業使用）。App 不提供下單、不提供投資建議，只讓使用者記錄自己的交易、
查看持股與個股的公開資訊，每一筆資料都標示來源。

目前個股頁有一列「相關股票」，依政府開放資料規則挑選（例如同產業、市值相近，或依〈董監事持股餘額明細〉判斷的關係企業）。
我們希望能加上「同一產業鏈的上游、下游公司」，貴中心〈產業價值鏈資訊平台〉的產業鏈分類與公司歸屬是最權威、最清楚的來源。

**我們想使用的資料**

- 產業鏈名稱與上、中、下游的分類（例如「半導體 → 上游：IC 設計」）。
- 各分類下的上市櫃公司代號（只需要代號與分類，不需要平台上的說明文字或圖表）。

**預計的呈現方式**

- 個股頁「相關股票」最多 4 格，其中 1–2 格可能是「同產業鏈上游／下游」的公司，格子下方寫一行理由（例如「產業鏈上游：IC 設計」）。
- 每次顯示都標示「資料來源：證券櫃檯買賣中心〈產業價值鏈資訊平台〉」並連回平台；不修改分類名稱、不加入我們自己的推論。
- 我們不會轉載平台上的文章、圖表或說明文字，也不會把資料另外提供或販售給第三方。
- 取得方式依貴中心指定（例如貴中心提供的檔案、API 或定期寄送）；在取得書面同意前，我們不會以程式擷取平台網頁。

**想請教的問題**

1. 上述用途是否可以使用？需要簽署何種授權或同意書？
2. 個人非營利階段與日後收費階段，授權條件或費用是否不同？若有費用，計價方式為何？
3. 是否有建議的資料取得方式（檔案格式、更新頻率、API）？
4. 顯名方式是否需要特定文字、標誌或連結？
5. 若日後貴中心要求停止使用，我們會立即移除；請問是否有固定的通知窗口？

若此詢問應改洽其他單位，也請不吝告知。謝謝您撥冗回覆。
