資產組成：疊色走勢圖的畫法比較

示意圖，數字是假的。三件事要選：虧損怎麼畫、股利放哪裡、縱軸要不要從 0 開始。墨色粗線一律是總資產。

一、虧損怎麼畫

賺錢時很單純：灰色的本金上面疊一塊紅色，疊到總資產。虧錢時總資產掉到本金下面，沒有東西可以「疊」，所以要選一種畫法。

二、股利放哪裡

領到的現金股利已經不在股票裡，所以不算在總資產。疊上去的話，最上緣會比總資產高一點（等於總資產加領過的股利）。

三、縱軸要不要從 0 開始

從 0 開始，每一塊的厚度才是真的比例；但看短區間時，總資產的起伏會被壓成一條平線。

五、本金不填色：只畫一條線，總資產在它上下波動

灰色階梯線是本金。總資產在線上面的部分塗紅（賺），在線下面的部分塗綠（虧）。
