## 0. 一頁結論

1. **上市股票的個股三大法人（T86）與外資持股（MI_QFIIS）不能拿來商用，除非付費或取得證交所書面同意。**
   - 證交所 OpenAPI 沒有任何法人端點；`/fund/` 底下只有「外資持股類股比率」與「前 20 名」兩個彙總表【事實】。
   - 政府資料開放平臺上有民眾建議開放「上市股票三大法人買賣明細」，機關回覆是：這是證交所**對外販售**的資料，放上平臺會和現行授權條款牴觸【單一來源】。
   - 證交所網站條款：網站內容未經書面同意不得重製、散布，**只有「已授權政府資料開放平臺」的資料例外**；也禁止未經同意用爬蟲下載【單一來源；櫃買同文【事實】】。
   - 合法商用路線：證交所 **Data E-Shop「三大法人買賣超檔」外部使用**（搜尋摘要顯示 NT$3,000／月）或寫信取得書面同意。
2. **上櫃股票可以商用。** 櫃買 OpenAPI 有逐檔法人買賣（`tpex_3insti_daily_trading`，2026-11-11 有 905 筆，含 ETF）與逐檔外資持股（`tpex_3insti_qfii`，898 筆）【事實】，在政府資料開放平臺以《政府資料開放授權條款－第1版》釋出【單一來源】。條件是**標示來源**；只有最新一天，歷史要自己存。
3. **「官方 OpenAPI＋每天自己存檔」是唯一零成本、可商用的主幹。** 授權條款明文允許「不限目的…重製、散布、公開傳輸…開發各種產品或服務」，唯一義務是**顯名聲明**；沒有標示就「視為自始未取得授權」【事實】。
4. **網站爬蟲（證交所、櫃買、期交所、MOPS 網站）在條款上都要「事前同意」。** 台灣實務上，違反網站條款爬取曾被一審法院認定為刑法第 359 條的「無故」（Lawsnote 案，2025-06，上訴中）【單一來源：多家媒體】；公平會也曾以公平法第 25 條處分用爬蟲搬運他人網站資料的業者【單一來源】。所以**商用爬蟲只爬「條款允許或已取得書面同意」的網站**。
5. **券商 API 的行情只能給開戶本人用。** 證交所辦法規定資訊用戶「不得將本公司交易資訊出租、出售或轉讓他人，或以任何方式再轉接他處」【事實】；富邦、富果的行情規範也禁止轉給第三人【單一來源】。所以券商 API 可以給產品負責人自己的帳戶用，**不能給家人朋友看，更不能商用**。
6. **FinMind 付費版也不解決授權問題。** FinMind 2026-10-31 的說明寫明：要對外公開或提供給第三方，「應自行確認並取得原資料來源機關所要求之相應授權；此類授權非 FinMind 所能授予或代為取得」【事實】。
7. **商用最低成本**：只用開放資料 NT$0／月；加上上市法人資料約 **NT$3,000–6,000／月**；要加延遲報價再 +NT$30,000／月；要即時報價至少 NT$100,000／月（證交所網際網路即時資訊，5,000 戶以內）【單一來源】。

**小結**：上市股票的個股法人與個股外資持股**沒有**開放授權版本。證交所的立場是這是付費商品。

### 1.2 證交所網站使用條款

證交所條款頁（[www.twse.com.tw/zh/terms/use.html](https://www.twse.com.tw/zh/terms/use.html)）在這個環境被 WAF 擋住，以下是搜尋摘要擷取的文字【單一來源】，和 1.6 節直接讀到的櫃買條款幾乎逐字相同：

> **智慧財產權**：「本網站所使用之軟體或程式、網站上所有內容，包括但不限於著作、圖片、檔案、資訊、資料、網站架構、網站畫面的安排、網頁設計，均由臺灣證券交易所或其他權利人依法擁有其智慧財產權。」除非事前取得書面同意，不得逕自使用、修改、重製、公開播送、改作、散布、發行、公開發表等；「但臺灣證券交易所已授權『政府資料開放平臺』提供公眾使用之本網站資料，不在此限。」引用或轉載時「請以適當方式清楚註明資料來源，並確保資料完整性，不得任意增刪」。
>
> **下載軟體或資料**：「非依臺灣證券交易所同意之方式或經臺灣證券交易所同意者，禁止透過包括但不限於自動化裝置、指令碼、自動程式、蜘蛛程式、爬蟲程式或擷取程式等方式下載本網站之軟體或資料。」
>
> **準據法**：中華民國法律，臺灣臺北地方法院為第一審管轄法院。

【推論】這兩條合起來的意思：
- **網站上的 T86、MI_QFIIS 不在例外範圍**（它們不是「已授權政府資料開放平臺」的資料）。
- **用程式從網站下載本身就需要同意**；OpenAPI 是證交所明示「歡迎介接」的方式，所以 OpenAPI 屬於「依同意之方式」。
- 「引用或轉載請註明來源」是在禁止條款之後的附帶要求，**不是**一般性的授權。

### 1.3 證交所《交易資訊使用管理辦法》（直接讀到原文）

來源：[regulation_use.pdf](https://www.twse.com.tw/downloads/zh/products/regulation_use.pdf)，最近一次修正 110-12-24（金管會 110-12-14 備查）。【事實】

| 條 | 原文（節錄） | 對 Forliosa 的意義【推論】 |
|---|---|---|
| 第 3 條 | 「三、交易資訊︰指本公司所開發或傳送之有價證券集中交易市場相關資訊及其衍生資訊。」「六、…較即時資訊延遲二十分鐘以上之交易資訊為延遲資訊。」「七、盤後資訊：市場交易時間以後所傳播之當日證券行情資訊為盤後資訊。」「九、資訊用戶︰指向申請使用者轉接傳輸交易資訊之用戶。」 | 三大法人是集中市場交易的衍生統計，很可能落在「交易資訊」定義內 |
| 第 5 條 | 「本公司提供之交易資訊屬本公司所有，如依法得為著作權、商標權、專利權之標的，其權利暨其他相關權益為本公司所有，如發現有剽竊、盜用或其他不法使用情事，本公司得依法追訴，並請求損害賠償。」 | 證交所主張資料屬於它 |
| 第 14 條 | 「申請使用者非經本公司同意，不得再將本公司交易資訊出租、出售或轉讓他人，或以任何方式再轉接至他處。」「申請使用者不得使用未與本公司簽訂『供給使用交易資訊契約』者所提供之交易資訊。」「證券商所營網站內提供之交易資訊…但經本公司同意者，證券商得以自行名義提供交易資訊予其開戶之投資人。」 | 券商 API 的資料是給「開戶之投資人」 |
| 第 27 條 | 「資訊用戶不得將本公司交易資訊出租、出售或轉讓他人，或以任何方式再轉接他處。」 | 從券商或資訊廠商拿到的資料，**不能轉給家人朋友或其他使用者** |
| 第 29 條 | 「申請使用者提供盤後資訊予其資訊用戶，得報經本公司同意後，不收取費用。」 | 盤後資訊對「已簽約的申請使用者」可免費，但要報經同意；Forliosa 不是申請使用者 |

## 3. 券商開放 API（只當資料來源，不下單）

### 3.1 共通規則

- 證券商是證交所的「申請使用者」，依辦法第 14 條第 4 項，經證交所同意，「證券商得以自行名義提供交易資訊予其**開戶之投資人**」；開戶人是「資訊用戶」，依第 27 條「不得將本公司交易資訊出租、出售或轉讓他人，或以任何方式再轉接他處」【事實：辦法原文】。
- 【推論】所以：
  - **(a) 產品負責人用自己的帳戶，在自己的 Forliosa 看**：符合「開戶之投資人」自己使用，前提是遵守該券商的同意書與流量限制。
  - **(b) 把產品負責人帳戶拿到的報價顯示給家人朋友**：屬於「再轉接他處」，不可以。可行的變通是**每個人用自己的券商帳號登入**（資料只回到帳號本人），但 Forliosa 伺服器替他們代管連線，仍可能被券商視為轉接，要先問券商。FinMind 對即時資料也是建議「讓使用者在你的產品輸入自己的帳號」，並說「請勿在產品內建你自己的帳號或 token」【事實：[商業使用 Q&A](https://finmind.github.io/CommercialUse/)】。
  - **(c) 商用**：券商無權轉授權；要商用就要直接和證交所／櫃買／期交所簽資訊供應契約，或向已簽約的資訊廠商買可轉載的授權（1.5 節的費用）。
- 下表的「條款」欄，除富邦與富果有搜尋摘要外，其他券商的**正式同意書都沒讀到原文**，需要各自詢問。

【推論】`robots.txt` 是給爬蟲的技術慣例，台灣沒有法律直接賦予它效力（[科技新報 2025-07](https://technews.tw/2025/07/12/the-liabilities-of-robots-txt/) 也這樣說），但法院判斷「無故」時會把「網站有沒有表示拒絕」當成重要事實。**網站沒有 robots.txt，不代表條款允許爬取**（櫃買就是例子：沒有 robots.txt，但條款明文禁止）。

### 4.4 爬蟲設計建議（只對 ✅ 與取得同意後的來源）【推論】

1. **來源白名單＋授權登記**：每個來源一筆設定：網域、允許的路徑、授權依據（條款網址、版本日期、或同意函編號）、顯名文字、頻率上限、是否可商用。不在白名單的網域，程式拒絕連線。
2. **優先順序**：官方 API／開放資料下載 > 官方檔案（CSV、ZIP） > 經同意的網頁。能用 OpenAPI 的一律不爬網站。
3. **頻率**：每個主機一個權杖桶；`*.twse.com.tw` 所有子網域共用一個桶（同一防火牆）；證交所 ≥3 秒一次、櫃買與集保 ≥2 秒一次；每日排程在官方公布時間之後（例如 14:40、21:40），不要盤中輪詢。
4. **誠實的身分**：固定 User-Agent，寫明「Forliosa data archiver」與聯絡信箱；**不偽裝瀏覽器、不輪換 IP 或代理、不解驗證碼、不帶別人的 cookie**。
5. **尊重拒絕訊號**：每天讀一次 `robots.txt`（讀不到或被 WAF 擋時視為「不允許」，只走 OpenAPI）；遇到 307、403、429 就指數退避，連續失敗就停用該來源並通知，不自動重試到成功。
6. **快取與冪等**：同一資料日只抓一次；有 `ETag`／`Last-Modified` 就用條件請求；存原始回應的雜湊，避免重複下載。
7. **出處欄位**：每筆存檔資料記 `source`、`url`、`fetched_at`、`license_id`；API 的 `sources` 文字由 `license_id` 產生，確保顯名聲明不漏（漏標＝自始未取得授權）。
8. **不散布原始資料**：app 只顯示經整理的數字與圖表，不提供整批下載或公開 API；付費資料（E-Shop）只顯示給登入使用者，頁面註明「資訊來源：臺灣證券交易所，不得再傳輸」。
9. **開關**：每個來源可單獨關閉；授權撤回或機關停止提供時，一個設定即可下架相關資料。
10. **個資**：含人名的資料（董監事、內部人）只存必要欄位，提供刪除管道。
