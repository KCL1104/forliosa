# 新聞與外部資料源研究（2026-11-12）

產品負責人要求：研究 public-apis 清單、FinMind、voidful 的三個 repo，以及「自己爬新聞（連結＋preview＋AI 讀取）」的可行性，全部研究後再討論。
參考畫面：`docs/research/refs/google-finance-2330-news.webp`、`google-finance-2330-overview.webp`；也看了 Goodinfo 與財報狗的個股頁。

研究限制：這個沙盒只能連少數主機，各家條款多半是**搜尋摘要轉述**，不是逐字讀原文（標【單一來源】或【推論】）。上線或寄信前，請在一般瀏覽器讀一次原文。
這份是產品決策用的背景，**不是法律意見**。

## 1. 結論摘要

| 問題 | 結論 |
|---|---|
| 新聞列表（原標題＋媒體＋時間＋連結） | **可以，低風險**。智慧局：「新聞標題僅屬簡短之文句，尚非著作權法保護之標的」（電子郵件 1140311）；超連結「點選連結後直接開啟原始網頁瀏覽，即不涉及重製與公開傳輸」（智著字第 11110018710 號）。條件：清單要由**我們自己的搜尋**產生，不要整批複製別家整理好的新聞清單（公平會「飢餓黑熊」案，公平法 §25） |
| Preview | AI 自己寫的一句**事實**摘要：中低風險（只寫誰、何時、數字、事件，不沿用原文句構或論點；智慧局說「摘要改寫」屬改作）。照貼導言或 og:description：中風險。**縮圖：高風險，不放** |
| AI 讀原文 | 使用者提問時即時讀、不存全文、短摘要附連結、遇封鎖就停：中風險，比自建爬蟲存全文安全很多。Anthropic 的抓取代理本身遵守 robots.txt、不繞過驗證碼 |
| 自建爬蟲掃媒體網站 | **高風險**：違反「禁止自動存取」條款可能構成刑法 §359「無故取得電磁紀錄」（Lawsnote 案一審有罪，已上訴）。不做 |
| 媒體 RSS | 中央社、自由、Yahoo 股市、MoneyDJ、公視的 RSS 條款都只准**個人／非營利、非商業**使用；鉅亨沒有官方新聞 RSS；聯合、中時、ETtoday 沒找到 RSS 條款（沒有明文允許） |
| 新聞 API（public-apis） | 免費又可商用的只有 **Currents API**（定價頁寫 Free 也可商用，要標示並連回原文；但正式條款有落差，要書面確認），而且台灣中文涵蓋沒證據。其他（MarketAux、NewsAPI、GNews、NewsData、Finnhub、Mediastack…）免費方案都限個人或開發用途 |
| 美股報價、股利 | public-apis 裡**沒有任何免費方案**能由我們伺服器取得再顯示給別人。Tiingo 的「使用者自帶金鑰」例外存在，但免費方案（2026-10-06 條款 §1.6）不准持久保存，做不到股利自動入帳，分享給家人也違約。只剩付費或空狀態 |
| 上市個股三大法人／外資持股 | 國際 API 都沒有。合法免費的只有證交所 OpenAPI `MI_QFIIS_sort_20`（外資持股前 20 名）與 `MI_QFIIS_cat`（類股）；其他上市個股維持空狀態 |
| ETF 淨值／折溢價 | 金管會證期局 data.gov.tw 11109〈證券投資信託基金每日淨值〉（政府資料開放授權）**可能**含 ETF；含的話可以用收盤價自己算盤後折溢價。要先驗證（需要開放 data.gov.tw 主機） |
| 分析師評等／目標價 | 沒有免費且有授權的結構化來源；維持 AI 搜尋的「法人觀點」 |
| FinMind | GitHub 的 Apache-2.0 只涵蓋程式碼；資料 Free／Backer／Sponsor 都是「非商業用途」，Sponsor Pro（NT$3,330／月）也不含對外散布，要原機關授權。維持只在 `personal` 模式 |
| voidful 三個 repo | 都不能直接用（見 §6） |

## 2. 法律基準（摘要）

- **標題**：智慧局電子郵件 1140311（114-03-11）「由於新聞標題僅屬簡短之文句，尚非著作權法…保護之標的」；智著字第 0920003842-0 號意思相同，但提醒仍可能依公平交易法等判斷。
- **超連結**：智著字第 11110018710 號（111-10-27）；例外是明知被連結的網站侵權（最高法院 109 台上 2616、110 台上 8 都是連到盜版）。連到媒體官網原文不受影響。
- **§9 I(4)**「單純為傳達事實之新聞報導」範圍很窄；記者撰寫、有分析的報導通常受保護。
- **§61** 只適用時事「論述」，而且「未經授權不得轉載」就排除；對我們用不上，也不需要。
- **§52 引用**要有自己的著作為主體；純新聞列表很難主張。§65 合理使用四項基準，商用不利。
- **摘要**：智慧局電子郵件 1050412「將此類新聞摘譯、摘要後，上傳…涉及『改作』…應經著作財產權人之同意或授權」；安全的做法是只陳述事實（§10-1：不保護觀念與事實）。
- **AI 讀取**：§22 III、IV 暫時性重製例外是否涵蓋 AI 代讀，沒有實務見解；台灣沒有文字與資料探勘（TDM）例外（修法研議中）。
- **爬蟲**：刑法 §359；Lawsnote 案新北地院一審（2025-06-24）以「違反網站使用規範」認定「無故」，判 4 年、2 年，賠償約 1 億元（已上訴）。robots.txt 沒有直接法律效力，但在「無故」與合理使用判斷上有份量。
- **公平法 §25**：公平會公處字第 111070 號（飢餓黑熊）：整批抄用別人整理好的網址與資訊，即使不擁有原文著作權，仍屬顯失公平。

需要律師的時點：開始收費或放廣告之前；想放縮圖或摘錄超過一句；任何媒體來函；要和媒體簽約；Lawsnote 二審或智慧局《生成式 AI 著作權指引》正式版出爐後。

## 5. 美股（報價、股利、評級）

- 免費方案都限個人或內部使用：Finnhub、Alpha Vantage、Twelve Data（§2.3 禁止免費版商用）、EODHD、Marketstack、Massive（原 Polygon）、FMP、Stooq、Alpaca、Tradier。
- **Tiingo**：使用者自帶 token 的例外有明文，但免費方案條款 §1.6（2026-10-06）禁止持久保存資料與衍生結果；分享給他人也違約。所以只能「頁面即時抓、即時顯示、不落地」，做不到股利自動入帳與 M5 分享。
- 可用的輔助：**OpenFIGI**（代號對照，公共領域／MIT）；**SEC N-PORT**（美國 ETF 季持股，公開申報）；**SEC 8-K** 可用 AI 從股利宣告抽出金額與日期（ETF 配息不在 EDGAR）。
- 付費參考：Marketstack Basic US$9.99／月（顯示權待確認）；Twelve Data Venture US$149 或 499／月（含對外顯示）。

## 6. 社群專案與資料商

- **FinMind**：資料授權依方案（Free／Backer／Sponsor 非商業；Sponsor Pro NT$3,330／月商業但不含對外散布，「應自行確認並取得原資料來源機關所要求之相應授權」）。官方建議即時、分點類資料讓使用者在產品裡輸入自己的帳號。
- **voidful/tw_news_stocker**：新聞來源是 Google News RSS（條款限個人使用），做的是新聞情緒排行（可能觸及投顧法規）；沒有授權檔，程式碼不能直接用。
- **voidful/tw_stocker**：5 分鐘 K 線，來源是 Yahoo Finance（yfinance），資料停在 2026-04-01；沒有授權檔。不能用。
- **voidful/taiwan-company-network**：2019 年的 React 範本（MIT 屬範本作者）。背後的資料〈公司登記董監事資料〉（data.gov.tw 96731／13863，經濟部商業發展署，政府資料開放授權）可以商用，「所代表法人」欄位可做法人董監／集團關係；要開放 `data.gcis.nat.gov.tw`，不存自然人姓名。

## 7. 待驗證

- data.gov.tw 11109 是否含上市 ETF、是否仍每日更新（需要開放 data.gov.tw 或由產品負責人下載一次）。
- Currents、NewsData 的書面確認；GDELT 的台灣中文涵蓋實測。
- 各媒體 RSS 的實際網址與 robots.txt（沙盒連不到）。
