## 完成了什麼

### 後端（`apps/api`，Python FastAPI）

- **台股稅費規則**：手續費（折扣、無條件捨去、最低手續費、零股最低）、證交稅（股票 0.3%、ETF 0.1%、當沖 0.15% 至 2027 年底、債券 ETF 免稅至 2026 年底）、二代健保 2.11%（單筆 ≥ 2 萬）、美股股利預扣 30%。
- **帳本**：移動平均與 FIFO 兩種成本法、配股、分割、減資、當沖配對、只記持股模式。
- **績效**：TWR、XIRR、最大回撤、年化波動度、1D／5D／1M／3M／6M／YTD／1Y／全部，比較基準可選 0050、加權報酬指數、006208、VOO。
- **資料來源**（依序備援）：證交所盤中報價 → shioaji-data（2,007 檔公司資料、月營收、財報）→ FinMind（歷史股價、本益比、股價淨值比、殖利率、股利、匯率）→ 示範資料。台股全部是真實資料；**只有美股是示範資料**（畫面有標示）。
- 所有 API 端點、登入 session、資料庫遷移、示範帳號（60 筆交易，含真實的玉山金配股與 0050 分割）、背景工作骨架、Dockerfile 與 Railway 設定。
- **測試：102 個全部通過**，lint 乾淨；也在 PostgreSQL 與 Docker 上驗證過。

### 前端（`apps/web`，Vite＋React）

- **完整走過 Impeccable 流程**：init → 6 個頁面的 shape → 實作 → document（`DESIGN.md`）→ extract → 每頁 critique（修完所有 P1）→ audit → adapt／harden／onboard／clarify／polish → detect 掃描 0 個問題。報告在 `.impeccable/reports/`。
- **頁面**：總覽、持股、個股頁（總覽、K 線、本益比與股價淨值比河流圖、財務、股利、我的交易）、交易（新增、編輯、刪除、即時稅費預估、復原）、績效、設定；自選先存在本機；AI 助理、報告、群組、匯入是設計好的「即將推出」頁面。
- **台股慣例**：紅漲綠跌（可切換）、「X 張 Y 股」、萬／億縮寫、隱私模式、等寬數字、⌘K 用中文股名搜尋。

## 在本機跑起來

```bash
cd apps/api
uv sync
uv run python -m forliosa.seed
uv run uvicorn forliosa.main:app --port 8000
```

另開一個終端機，在 repo 根目錄：

```bash
pnpm install
pnpm dev:web:api
```

打開 http://localhost:5173，會自動以示範帳號登入。只想看畫面、不跑後端：`pnpm dev:web`。
