# Impeccable 審查報告（追蹤版）

`impeccable critique-storage` 會把快照寫到 `.impeccable/critique/`，並在那裡放一個忽略自己的 `.gitignore`（視為本機狀態）。為了讓產品負責人能在 repo 裡看到這一輪的審查結果，這裡保留一份副本：

- `critique/`：7 個頁面的 critique（2026-11-11，單一上下文降級模式；第一行有標示）
- `audit/`：整個 `apps/web` 的 audit（引擎 0.1.22 沒有 `audit-storage`，手動存放）

`/impeccable polish` 讀的是 `.impeccable/critique/` 裡的原檔。
