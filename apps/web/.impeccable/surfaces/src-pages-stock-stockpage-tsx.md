# Surface: 個股頁 `/stock/:symbol`

`/impeccable shape 個股頁` 的產出（無人可回答，假設標示〔推論〕）。繼承 shell 視覺世界。

## Job and audience

- Operate、資訊密集（對標 Yahoo 股市個股頁與「價值評估」頁）。使用者從持股表、⌘K 或首頁進來，想知道：現在多少、今天漲跌、貴不貴（估值河流圖）、營收成長、配多少息、我在這檔賺多少。

## Structure

- **頁首**：名稱（大）＋代號＋市場／產業章；現價（NumberFlow）、漲跌與幅度（方向色＋▲▼）、成交量（張）、資料時間（「13:30 收盤」或「延遲報價」）；動作：加入自選（M2，可切換狀態，存在本機）、問 AI（M4，按下顯示說明 popover）。
- **分頁**（Base UI Tabs，網址同步 `?tab=`）：總覽、K 線、估值、財務、股利、我的交易、籌碼（即將推出）、新聞（即將推出）、AI 報告（即將推出）。手機上分頁列可水平捲動。
- **總覽**：關鍵數字網格（開高低收、昨收、成交量、市值、本益比、股價淨值比、殖利率）＋公司小卡（簡介、產業鏈位置、題材章、資料來源）。
- **K 線**：lightweight-charts 蠟燭圖＋成交量；區間 5D/1M/6M/YTD/1Y/5Y/全部；MA5/MA20/MA60 〔推論：先做均線，其他指標之後〕；標示 TradingView 授權。蠟燭顏色依漲跌慣例。
- **估值**（重點）：子切換「本益比河流圖／股價淨值比河流圖」；圖為收盤價線＋5 條倍數帶（eps_ttm × per_multiples 或 bvps × pbr_multiples）的堆疊色帶，由便宜到昂貴的色階（藍印→石→淡朱），不用紅綠（避免與漲跌混淆）。右側（手機在下方）：目前本益比、所在區間（例如「介於 16–20 倍」）、5 年百分位；殖利率走勢小圖。EPS ≤ 0 的期間：本益比帶留白並在圖上方說明「近四季 EPS ≤ 0，本益比沒有意義，這段期間不畫區間」。
- **財務**：月營收長條（千元 → 億元顯示）＋年增率折線（雙軸），下面表格（月份、營收、月增、年增、累計年增）。
- **股利**：歷年現金／股票股利表與長條、殖利率；即將除息日醒目。
- **我的交易**：這檔的持有（張股、均價、未實現）＋交易清單（`/transactions?symbol=`）＋新增交易按鈕（帶入代號）。

## States

- 找不到代號（404）→ 說明＋回搜尋。美股：無本益比河流圖資料時顯示說明、財務分頁顯示「美股財務資料規劃中」。載入骨架；錯誤可重試。所有 `is_demo` 回應顯示示範章。
