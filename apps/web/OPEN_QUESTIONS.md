# 前端待確認事項（給產品負責人）

前端這一輪在產品負責人睡覺時完成，以下是我自己做了決定、但需要你確認的地方。每項都寫了目前的做法；改起來都不難。

## 設計方向

1. **視覺世界觀「印鑑與朱泥」**：Impeccable 的 concept-seed 擲骰指定了我自有清單的第 7 名（印鑑與印台）。資料狀態用方形「章」標示（示範資料、預估、已入帳、M4 推出），朱泥紅只出現在品牌章（因為紅色代表「漲」）。沒有人可以在決策頁選擇，所以直接採用；網路開通後重擲取得 6 個 catalog challengers，沒有一個在兩軸都勝出（評比見 `apps/web/.impeccable/surfaces/src-pages-home-homepage-tsx.md`）。**要換方向嗎？** 我自己的首選（未採用）是「存摺」。
2. **品牌章**是朱泥白文方印「F」。目前沒有正式 logo，之後若有會替換。
3. **字型**：Source Sans 3＋Noto Sans TC（思源黑體）。若偏好 Windows 的微軟正黑體或 iOS 的蘋方，可以改成系統字型（少下載約數百 KB）。

## 資料與 API（需要和後端對齊）

4. **首頁 1D／5D 走勢**：`/portfolio/performance` 的 range 只有 1M/3M/6M/YTD/1Y/ALL。目前 5D 由 1M 資料裁切最後 6 天，1D 只畫昨收→今收兩點並註明「盤中走勢要等即時行情（M2）」。要不要讓後端支援 `1D`（盤中）與 `5D`？
5. **手續費四捨五入或捨去**：api-contract 範例 1,070,000 × 0.1425% × 2.8 折 = 427（四捨五入），但不少券商實務是無條件捨去（426）。mock 跟著合約用四捨五入；正式規則請後端確認（spec §4.3 沒寫）。
6. **基準「發行量加權股價報酬指數」**：設定頁目前只提供 0050、006208、VOO 三個選項；報酬指數需要後端資料。mock 一律用 0050 計算。
7. **隱私模式範圍**：目前遮蔽金額與股數，**保留百分比**（報酬率、權重、漲跌幅），績效頁的金額圖表整張隱藏。這樣截圖分享時仍可看出績效。OK 嗎？
8. **均價顯示**：持股表的均價（`avg_cost`）屬於成本資訊，隱私模式下目前**沒有**遮蔽（只遮金額與股數）。要遮嗎？
9. **ETF 的估值頁**：ETF 沒有 EPS／淨值，估值分頁只顯示殖利率走勢並說明原因。若想看 ETF 的折溢價，需要新的 API。
10. **示範資料**：mock 的「今天」固定為 2026-11-11 13:30（截圖穩定），但交易表單的預設日期用真實的台北日期。

## 功能範圍

11. **自選（M2）先存在本機**：個股頁的「加入自選」現在存 localStorage，自選頁會列出並抓報價。API 合約還沒有 watchlist 端點。
12. **新增帳戶**：設定頁可新增／編輯帳戶（名稱、券商、幣別、追蹤方式、折扣、最低手續費）。**刪除帳戶**（會連同交易刪除）刻意還沒放 UI，等確認確認流程。
13. **「只記持股」模式**：首頁的「輸入目前持股」目前開的是一般記交易表單（以買進＋均價記錄）。若帳戶是「只記持股」，應改用 `PUT /accounts/{id}/holdings` 的快照表單——要做成獨立的批次輸入畫面嗎？
14. **交易紀錄的刪除**：表單內刪除用「復原」通知（不跳確認）；桌面清單上的垃圾桶按鈕仍會跳確認對話框（避免在密集清單誤按）。

## 函式庫

15. **Vaul 已停止維護**：仍依規格使用（shadcn Radix 版 Drawer）。Base UI 1.x 已內建 `Drawer`（shadcn base 版就是用它），建議 M2 時改用，少一個依賴、也統一到 Base UI。
16. **motion 沒有用到**：所有動畫用 CSS 就夠，已從依賴移除；之後需要拖曳手勢或 layout 動畫再加回。
17. **展示性元件（Magic UI、Aceternity 等）一個都沒用**：理由見 `docs/ui-libraries.md`。M5 群組排行榜是最適合的地方。

## 需要實機確認

18. Safe area（瀏海、Home 指示條）、軟體鍵盤打開時的抽屜、iOS 輸入框不放大——都是在模擬器驗證，需要在真的手機上看一次（mobile-native skill 的規則）。
